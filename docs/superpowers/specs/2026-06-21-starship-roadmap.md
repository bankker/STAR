# 星舰炉石 · 宏观结构 / 成长系统 / 内容扩展路线图

> 战斗内核照炉石；内容深度照单机 roguelike 卡牌（杀戮尖塔 / Inscryption）。本作是单机叙事恋爱向 PvE，深度来自 **关卡变化 + 构筑成长 + 流派协同**，三者均可与恋爱养成焊接——「加战斗深度」与「加角色/剧情」是同一份工作（炉石做不到）。

## 1 宏观结构：混合式（作者章节 + 章节内节点地图）【定稿】
章节 = 一段恋爱/剧情主线 + 一张小型节点地图（入口→Boss，沿途分叉）。节点类型 ≥4：**战斗 / 精英 / 事件·对话 / 补给**，章末 Boss。一局 = 走完一张章节地图（roguelike 容器）。两场战斗间的角色对话 = 地图上的站点，不是旁白——「融合」的物理落点。

## 2 三层成长（正交，对应三种时间尺度）
| 层 | 尺度 | 内容 | 失败时 |
|---|---|---|---|
| 养成层（永久升级） | 整个游戏 | 武器升级树 / 仓位·功能舱 / 船员强化 → 决定「带什么上船」 | 保留 |
| roguelike 层（单局遗物） | 一趟 | 改装模块 / 单局货币 → 决定「这一趟怎么打」 | 损失（见 §5） |
| 战斗层（回合） | 一场 | 能量配电 × 手牌 × 站场 | — |
**纪律：永久升级只扩展可能性（能做哪些 build），不给碾压数值；强度爬升交给单局遗物。** 否则碾平关卡、废掉遗物层与回合策略（同类游戏最常见崩盘点）。

## 3 永久升级（养成层）
- **3.1 武器/设备升级树**：形态分叉非直线数值，升级树 = 流派养成路径。部位×路线：主炮(重炮/连射/贯穿)、护盾(硬盾/反震/相位)、反应堆(高功率/速充/过载)、维修(群疗/单疗净化/续航)、弹药库、传感器。**解锁永久、配置可切换**——出战前自由组合带哪套上船（针对敌人换 build）。升级路线 = 流派 = 特定船员解锁/强化（§6 接点）。
- **3.2 仓位/功能舱**：仓位 = 同时上场核心船员数（复杂度+强度旋钮）。基础 4，**硬上限 6**；扩仓是里程碑（完成角色线/打通章节才 +1）。仓位通用：战斗位 vs 功能舱（医疗/能源/机库）权衡。「谁上场谁休整」= 情感取舍（心 vs 略）。

## 4 关卡变化（roguelike 层 · 最大内容空缺）
- **4.1 敌人原型库**（换谜题非换皮，深度最高成本最低）：铺场流→逼AOE / 肉盾流→逼爆发 / 竞速流→逼快攻 / 控制流→逼换打法 / 机制流（每N回合EMP瘫痪一名船员）。
- **4.2 战场环境/地形**（一句话改全场）：星云(护盾失效) / 恒星风(攻击随机目标) / 小行星带(掩体嘲讽) / 引力井(能量±1)。
- **4.3 敌方意图预告**【PvE 必备】：敌本体显示下回合行动（集火 ⚔12 / 召唤僚机 / 蓄力）。无它则「攻还是防」是赌博；有它战斗成为可推演的谜题。精度可由传感器升级提升。

## 5 失败与代价【定稿】
失败损失「这一趟攒的」，不损失「你是谁、和谁的关系」。
- 损失：本趟遗物（清空）、单局货币（损失大部分，保留 ~25%）、地图进度（退回章节入口重选路线）。
- 绝不损失：永久升级、角色好感/关系、剧情主线进度。
- 副作用：让补给节点+单局货币有真实重量。
- **5.1 失败叙事余波（可选，默认开）**：团灭回船触发一小段船员对话（确定性触发 + LLM 写一句），不掉好感，把「打输」转成「一起撑过来」反喂羁绊。

## 6 流派协同（构筑深度 = 角色深度）
关键词 5→~10（连携、过载/借能、蓄力、标记集火、反震、续航护甲…）。长出流派：导弹爆发/护盾反震/无人机海/维修磨血/标记集火。**每个流派由特定船员解锁/强化 → 加一个流派 = 加一个可攻略角色 + 剧情线。**

## 7 差异化（炉石框架物理做不出）
船员实时反应台词（护盾快破/暴击/挡刀，确定性触发+LLM 点缀，直喂「共患难→羁绊」）；打击感弹道动效（已有）；阵营/Boss 主题曲（复用音乐生成）。

## 8 分期
- **阶段一（最高性价比，先做）**：敌人原型库 4~5 个 / 地形 3~4 种 / 敌方意图预告 / 单局遗物+战后三选一+卡牌升级 / 章节节点地图（容器，尽早搭骨架）+ 失败规则。
- **阶段二**：武器升级树（主炮/护盾/反应堆三部位）/ 仓位第5格+功能舱 / 关键词扩展+2~3 流派。
- **阶段三**：事件对话节点内容 / 实时反应台词+失败余波 / 流派随艺人逐个滚动（每新艺人=新流派+新角色线）。
- 依赖：节点地图是 roguelike 内容容器（阶段一尽早）；武器树依赖内核稳定；叙事可与阶段二并行。

## 9 对 MVP 战斗文档的衔接修订
1. **敌方意图预告**（§4.3）：敌方单位需暴露「下回合行动」字段（engine 计算 `state.intent`）。
2. **站场上限可成长**：「核心船员固定 4」→「基础 4，可永久升级至上限 6」（§3.2）；平衡锚（舰体 30 / 能量 10）不变。

## 现状（已实现）
战斗内核（25 单测）/ 四屏 1:1 comp（战斗·编成·对话·星图）/ run 串联 / 真人艺人三屏立绘 / LLM 实时对话。本路线图在此之上扩展。
