# 故事模式 · 设计文档（v0 草案）

> 一部 **2D 银河史诗 × 恋爱养成**互动游戏。你是星海乱世中崛起的指挥官，主演是**你创建的虚拟艺人**。叙事亲密感像《恋与深空》，世界气质像《银河英雄传说》，战斗是《光荣/CK》式的**轻量战法卡**——全程 2D，回合制，无 3D、无实时。

## 已锁定方向（来自需求确认）
1. **玩家定位**：崛起的指挥官（银英传式个人视角）
2. **角色阵容**：用用户已创建的虚拟艺人当主演
3. **恋爱比重**：**恋爱养成为核心，战略为背景/舞台**（全程 SFW 情感向）
4. **战斗深度**：轻量战法卡（选战法 + 克制 + 地形结算）先做

### 细化决策（v0.1，已定）
- **战法环**：3 张石头剪刀布（突击/包抄/诱敌）+ 统率·地形·士气修正。
- **回合节奏**：月回合 + 行动点（每回合＝1 月，1 主事件 + 1~2 行动点谈角色；战役数回合一次；一局约 15~20 回合到一章结局）。
- **主角**：第一人称·无立绘；仅设 指挥官名 / 称号 / 性别取向（用于称呼与恋爱线）。
- **故事档案**：入局时 LLM 依艺人人设/魅力/背景一次性评定初始数值（可手调），几乎零额外录入。

## 体验主轴
核心是**关系养成**：通过对话场景、并肩作战、共渡危机，与角色逐步加深羁绊。
银河战争是**舞台与节拍器**：战役推进剧情、制造"并肩 / 负伤 / 抉择"的名场面，胜负的情感余波回流到关系层。战略轻量，不喧宾夺主。

## 世界观骨架（银英传味）
- **两极**：`新帝国`（秩序·门阀·强军）vs `自由同盟`（民主·腐败·名将），中间 `费沙`式星际商业自治区（情报与金钱枢纽）。
- **星图**：可平移的 2D 节点图，节点＝星系/要塞，连线＝航路；星域地形（星云遮蔽 / 恒星风 / 回廊要塞）影响战斗。
- **角色即命运**：名将的抉择改写战局——银英传的魅力点。

## 核心循环（一个回合 ＝ 1 个月，含 1~2 行动点）
1. **关系/事件阶段（主）**：视觉小说式场景——生成背景 + 角色立绘 + 对话 + 选项；选项影响好感、心情、数值与剧情分支。日常 + 个人线 + 危机事件。花**行动点**主动找角色互动。
2. **战略阶段（轻）**：星图上派角色领舰队/守要塞/出使；分配补给/政治资本/情报。
3. **战役阶段（轻量卡）**：选一张战法卡（突击/包抄/诱敌），数值结算，LLM 旁白 + 生成插画；并肩作战改变好感。
4. **结束回合** → 推进 1 月，银河推进、AI 行动、新事件浮现。一局约 15~20 回合到一章结局。

## 关键系统
### A. 羁绊（核心）
- 每角色：`好感 0–100`（分阶段：陌生→信赖→交心→…）、`心情`、`个人线进度`。
- 来源：对话选项、并肩作战、赠礼、关键抉择。高好感解锁个人剧情、战斗 buff（信任你的人在侧翼更强）、可选恋爱路线（SFW）。
- 角色的**人设/背景/外形**直接取自该艺人档案，让 Ta「在世界观里」说话。

### B. 角色与数值
- 故事档案（艺人档案的扩展）：定位（指挥官/参谋/谋臣/恋爱对象…）、阵营、`统率/谋略/政务/魅力/忠诚`、与玩家好感。

### C. 轻量战法卡战役（已定：3 张 RPS + 修正）
- 每军：兵力、士气、指挥官（统率影响战力底、谋略/魅力影响战法）。
- **三战法循环克制**：
  | 战法 | 吃数值 | 克 |
  |---|---|---|
  | 突击（正面强攻） | 统率 | 包抄 |
  | 包抄（机动迂回） | 谋略 | 诱敌 |
  | 诱敌（佯退设陷） | 谋略·魅力 | 突击 |
- **结算** = 兵力 × **克制系数**（克 ×1.5 / 平 ×1.0 / 被克 ×0.7）× 指挥官统率 × 地形 × 士气 + 受控随机 → 胜负 + 损失 + 士气 + 领土变动。
- **地形**：回廊要塞利突击、星云利包抄、恒星风利诱敌。
- 数值在后端**确定性计算**，LLM 只负责旁白文采 + 生成一张战役插画。
- 后续可扩到 5 张「五势环」。

### D. 轻量战略
- 领土→资源；资源→养舰队/升级；角色忠诚/好感→表现与背叛风险（CK 式权谋点缀）。

## 复用现有 app（独有卖点）
| 需求 | 复用 |
|---|---|
| 主演角色 | 现有**虚拟艺人**（人设/背景/立绘）+ 故事档案扩展 |
| 立绘/场景/插画 | 现有文生图（写真/定妆提示词体系）+ 新增星图/战役/议事厅提示词 |
| 对话/事件/旁白 | 现有聊天 LLM（角色 persona+背景为系统设定） |
| 存档 | 仿 `drama-store` 写 `story-store`，存 `DATA_DIR/stories`（已挂 GCS 卷） |
| OST | 现有音乐生成做阵营主题曲/战役 BGM |
| 成本控制 | 复用现有成本闸门；战斗确定性、事件可缓存 |

## 界面（全 2D，见招牌界面草图）
「故事」为**全画布视图**（进入后让出聊天框），含子视图：
- **事件/对话**（主）：背景 + 立绘 + 对话 + 选项（恋与深空式）。
- **星图**：SVG 节点图，势力着色，舰队 token。
- **议事厅/角色**：艺人立绘排布，数值与好感，派任务。
- **战役**：两军数值块 + 战法卡 + 结算 + 旁白插画。
- **角色档案**：个人线、回忆（生成图）、好感阶段。
- 顶栏 HUD：纪元/回合、资源、战役临近、结束回合。

## 数据模型（草图）
```
story（一局存档）: { id, name, turn, era, factions[], map{systems[],lanes[]},
  player{ name, title, pronoun, faction, actionPoints, resources{supply,politics,intel} },
  cast[ { artistId, role, faction, stats{统率,谋略,政务,魅力,忠诚},
          affinity, mood, routeProgress } ],
  fleets[], log[], flags{} }
event（事件/场景）: { id, sceneBg, speakerArtistId, lines[], choices[
  { text, effects{ affinity, stat, resource, flag }, next } ] }
battle: { attacker, defender, terrain, tacticChosen, result }
```

## MVP（垂直切片，先跑通一条线）
1 个星域（6–8 星系）+ 2 势力 + 3–4 个角色（取自艺人）+ 完整回合循环 + 星图 + 角色好感 + LLM 事件选项 + 1 种战法卡战役 + 存档。SFW。

### 之后分期
- P2：外交/权谋、恋爱个人线、赠礼、战役插画、OST。
- P3：胜利条件/多剧本、舰队编制深化、忠诚与背叛、结局分支。

## 已定（本轮打磨结论）
- 战法环＝3 张 RPS + 修正；回合＝月 + 行动点；主角第一人称无立绘；故事档案 LLM 自动评定。

## 留待实现期再细化
- 战法克制系数与随机区间的具体平衡数值（做出来跑手感后调）。
- 一章的剧情节拍模板（开局/转折/高潮/结局）与触发条件。
- 行动点与好感增长曲线（避免太肝或太快）。
- 星域初始布局与首章剧本（MVP 用一个手写星域）。
